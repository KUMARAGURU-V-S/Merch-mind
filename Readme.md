# 🧠 MerchMind
### AI-Driven Unified Intelligence Layer for Small Retailers

MerchMind is an **AI-powered RetailTech platform** that enables small retailers to seamlessly participate in online and omnichannel commerce.  
It acts as a **unified intelligence and middleware layer** between retailers and fragmented online marketplaces, removing the need to understand platform-specific rules, catalog formats, or workflows.

---

## 📌 Problem Statement

Millions of small retailers in India struggle to participate effectively in digital retail due to:

- Low digital literacy and language barriers
- Fragmented online retail ecosystems
- Manual and repetitive catalog, price, and inventory updates
- Lack of real-time inventory visibility
- Guesswork-based pricing and purchasing decisions

Retailers are forced to manage products, pricing, and stock **separately across multiple platforms**, leading to inconsistencies, operational inefficiencies, poor discoverability, and significant revenue loss.  
Inventory planning and demand estimation are largely manual, resulting in stockouts, dead inventory, and pricing mistakes.

---

## 💡 Solution

**MerchMind** provides an **AI-driven unified retail intelligence layer** that bridges small retailers with multiple online platforms through a single, simplified interface.

### Key Solution Components:

- **Omnichannel Marketplace Middleware**  
  Automatically synchronizes catalogs, inventory, and pricing across multiple online marketplaces without manual intervention.
- **Unified Catalog & Inventory Engine**  
  Converts all stock-in and stock-out data into a single standardized master catalog reusable across platforms.

- **Bill-Based Data Capture**  
  Retailers simply upload sales bills and purchase bills. The system automatically tracks:
  - Inventory levels
  - Stock-in and stock-out
  - Pricing consistency


- **AI Decision Engine**  
  Uses historical billing data and market signals to generate:
  - Demand forecasts
  - Buying recommendations
  - Price suggestions  
  helping retailers reduce errors and scale beyond local markets.

---

## 🔄 How MerchMind Works

1. **Retailer Uploads Bills**
   - Sales bills (stock-out)
   - Purchase bills (stock-in)

2. **AI Processing Layer**
   - Extracts structured data from bills
   - Standardizes products, quantities, prices, and SKUs
   - Updates the master catalog and inventory

3. **Decision Intelligence Engine**
   - Analyzes historical data
   - Generates demand, pricing, and purchasing insights

4. **Omnichannel Sync Engine**
   - Pushes clean, standardized data to multiple marketplaces automatically

## 🛠️ Tech Stack

### Frontend
- **React.js** – Dynamic and responsive UI
- **Tailwind CSS** – Clean, mobile-friendly design for non-technical users

### Backend
- **Node.js** – Business logic and data processing
- **Express.js** – REST APIs for catalog, inventory, and sync operations

### AI & NLP
- **Speech-to-Text** – Converts voice input in local languages
- **Text-to-Speech** – Voice-based responses and alerts
- **LLM-based Product Structuring** – Converts unstructured input into marketplace-ready data

### Database & Authentication
- **Firebase** – Centralized catalog storage, inventory data, pricing, and secure authentication

## 🚀 Getting Started

### Prerequisites
- **Node.js** & **npm**
- **Firebase** project setup (for database and auth)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-repo/merch-mind.git
   ```

2. **Install Dependencies**
   Navigate to the project directory and install the necessary packages:
   ```bash
   npm install
   ```

3. **Run the Application**
   ```bash
   npm start
   ```
